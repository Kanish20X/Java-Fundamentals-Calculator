# Building an advanced Java console calculator for my Elevate Labs internship. This project covers core concepts like the Scanner class, nested loops, and modular methods.

## Project Description
A robust, menu-driven console calculator built during my Java Developer Internship at Elevate Labs. This project goes beyond basic two-number arithmetic by implementing a "running total" logic, allowing for continuous calculations. It focuses on clean code principles, including modular programming and comprehensive error handling.
Features

**Continuous Operations**: Supports a "running total" mode where you can keep adding, subtracting, or multiplying numbers until you hit the = sign.

**Modular Arithmetic**: Uses dedicated, separate methods for each mathematical operation to ensure code reusability.

**Multi-Session Support**: An outer loop allows you to finish one calculation and start a brand-new session without restarting the application.

**Error Handling**: Prevents program crashes from invalid non-numeric inputs and includes specific checks for division-by-zero errors.

**Formatted Output**: Uses precise string formatting to display the full operation (e.g., 5.0 + 2.0 = 7.0) for a better user experience.

## Technologies Used

    Language: Java (JDK 17+)

    Tools: VS Code / Terminal

    Core Concepts: Methods, Conditionals (if-else), Nested Loops (while/do-while), and Scanner I/O.

## How to Run

    Clone the repository to your local machine.

    Open your terminal and navigate to the folder.

    Compile the file:
    javac Console_Calculator.java

    Run the application:
    java Console_Calculator
